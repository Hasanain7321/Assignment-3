## 🛠 Project Architecture & Structure

This project follows a clean, modular architecture designed for scalability and performance.

```text
root/
├── src/
│   ├── api/            # API integration & service layers
│   ├── components/     # Reusable UI components (Atoms, Molecules, Organisms)
│   ├── constants/      # App-wide constants & design tokens
│   ├── context/        # Global state management (Auth, Cart, Theme)
│   ├── screens/        # Project-specific screen implementations
│   │   ├── Auth/           # User Authentication System
│   │   ├── Ecommerce/      # Full-featured Shop & Checkout
│   │   ├── SocialMedia/    # Feed, Posts, and Engagement
│   │   ├── TicketBooking/  # Event Management & Seat Selection
│   │   ├── ExpenseTracker/ # Financial Management & Reporting
│   │   └── FoodDelivery/   # Multi-vendor Food Ordering
├── assets/             # Optimized image & font resources
├── scripts/            # Utility scripts for development
└── App.tsx             # Core application entry point & routing
```

## 🛠 Getting Started

### Prerequisites
- **Node.js** (v16 or higher)
- **npm** or **yarn**
- **Expo Go** app on your physical device (optional)

### Installation
1. Clone the repository and navigate to the root:
   ```bash
   npm install
   ```

2. Start the application:
   ```bash
   npx expo start
   ```

3. Scan the QR code with **Expo Go** (Android) or the **Camera app** (iOS).
